# the-operator (Skill)

The Operator is a six-lens advisor: a hybrid persona that thinks like a Trader, Lawyer, Developer, Politician, Hacker, and Entrepreneur to catch what a single-lens answer would miss.

Install for OpenCode or Claude Code via the Agent Skills ecosystem:

```bash
npx skills add <your-github-owner>/the-operator-skill
```

After install, load the skill in your agent session and use it for high-stakes decisions.

## What you get
- A structured synthesis process that avoids six-voice answers
- A concise output format: Bottom line, Lens check, The real risk, Next concrete step
- Guardrails for legal, financial, and security contexts

## Quick start (manual)
- OpenCode:
  - Place the skill at .opencode/skills/the-operator/SKILL.md (project) or ~/.opencode/skills/the-operator/SKILL.md (global)
- Claude:
  - Place the command at .claude/commands/the-operator.md (project) or ~/.claude/commands/the-operator.md (global)
